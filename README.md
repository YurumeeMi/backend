# sumiledger

> to build use
> docker compose build 
> docker compose build cli 
(in rootdir only)

you can refer to API.md for the api wiring into your own web app

the cli can be accessed by 
> sudo docker compose run --rm cli

the tui uses keys

q - quit
a - create account
esc - escape the create accoun
down/up - to change the page
